# 티비위키 1.0.9 규칙 적용 기록

소스와 색인 버전·확장 ID 유지, 안전한 선택자, 주소 자동 찾기 설정과 확인 후 저장, 연결 실패 재시도, 목록 시간 제한과 캐시, 검색 보완, 필요한 회차 번호 보정, 영화 본편 이름, 날짜, 실제 메타데이터에 따른 상태, HLS 인식과 실제 제공 화질·후보, 선호 화질, 루트 수정 이력과 문서 생성을 적용했습니다.

기존 재생 세션 방식은 유지했으며 키 변조나 중계 서버를 새로 추가하지 않았습니다. 사이트가 제공하지 않거나 현재 확인할 수 없는 장르·방영 상태·연도·대체 서버는 만들지 않습니다. 목록 제목은 상세에서 확인한 정보를 재사용하며 표지·날짜 때문에 상세를 여러 개 미리 읽지 않습니다.

검사: Node 구문 검사와 모의 입력 검사. 실제 사이트 접속·순정 망가요미 실기기 재생·사이트 전체 검색 60개 검사는 미확인입니다. 전 규칙 실기기 검증 완료를 의미하지 않습니다. Kotlin·신규 사이트 비교 규칙은 기존 JS 소스 보완에 해당하지 않습니다.

## 1.0.10 타이머 호환성 수정

clearTimeout 없는 환경, Promise를 반환하는 setTimeout 환경, 두 타이머 모두 없는 환경을 검사합니다. 성공과 원래 통신 오류를 보존하며 타이머가 있을 때 시간 초과와 늦은 완료를 검사합니다. 타이머 자체가 없으면 Client의 통신 timeout에 맡깁니다. 실기기 동작 확인은 별도입니다.
