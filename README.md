# 시험 저장소 (망가요미)

새 확장이나 큰 수정을 정식 배포 전에 휴대폰에서 시험하는 곳. 이 가지에 올려도 빌드·배포 작업은 돌지 않음.

- 망가요미 애니 칸에 추가할 주소:
  `https://raw.githubusercontent.com/insid0909-max/aniyomi-extensions/test/index.json`
- 시험판은 이름 앞에 "[시험]", 정식판과 다른 시험용 id 사용.
- `sourceCodeUrl` 은 이 가지(test) 주소. 칸을 옮기면 index.json 의 주소도 같이 고침(id·이름은 그대로 — 바꾸면 서재 연결이 끊길 수 있음).

## 보관 칸 (2026-11-10, 사용자 요청)

| 칸 | 폴더 | 뜻 |
|---|---|---|
| 시험 중 | `js/testing/` | 아직 휴대폰에서 시험하고 고치는 중 |
| 정식 배포 전 | `js/ready/` | 휴대폰에서 잘 되는 것 확인 — 사용자가 정식 배포를 허락할 때까지 대기 |

정식 배포는 **사용자가 허락할 때만** master 의 `mangayomi/javascript/anime/src/ko/` 와 `anime_index.json` 에 정식 id 로 올리고, 여기서는 지움.
