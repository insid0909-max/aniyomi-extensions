# 애니요미 시험 APK 로 빌드할 확장 모듈 (src/ko/<모듈>) — 한 줄에 하나: 모듈 칸 [sites=사이트,사이트] 메모
# 칸: 시험중 = 휴대폰에서 시험·수정 중 / 배포전 = 휴대폰 확인 끝, 정식 배포 허락 대기
# sites= : 시험판에 넣을 사이트 이름(일부만 써도 됨, 쉼표로). 없으면 그 모듈의 사이트 전부 → 시험할 사이트만 적을 것
#   예) tvroom 시험중 sites=티비위키 티비위키 재생 고침
#       livesports 배포전 sites=실시간스포츠1
# 시험할 게 없으면 줄을 모두 지우거나 # 를 붙임 → 시험 저장소가 비어 있게 됨
tvroom 시험중 sites=확장 상태판 확장 상태판 애니요미판 (2026-11-13)
